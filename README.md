# Nighttime Lights of Cities
This repository includes programming codes to analyze economic activities in cities, using satellite images as a proxy to estimate GDP & advancement of nighttime lights of studied areas.
## 💡 Overview
Night-time lights serve as an efficient tool to study the economical development, especially, during rapid redistribution of wealth, economy and demography
## 📊 Methodology
I have relied on simplified methodology in three steps:
1. Data Collection: Downloading data using mainly NASA Earth-Data: https://www.earthdata.nasa.gov/.
2. General Processing: Matching boundaries, filtering &...etc.
3. Calculations & Visualization: Plotting heatmaps and curves indicating studied indicators.
## 🛠 Requirements
I have used R language, which is known for its advanced libraries and tools to deal with analytical projects. You have to install the following libraries: 'ggplot2', 'tidyverse', 'sf', 'terra', 'geodata', and 'inequality'. You can also use Python instead but R still easier and more productive.
